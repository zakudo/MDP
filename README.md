Basically the project is regarding pzioelectric tiles , 
we have hardware part whose input is taken in database(firebase) and from there it is reflected on website(frontend) , 
the website has login page and main dashboard.
The dashboard consist of many toggle buttons which includes graphs, past history data , theme change button and login logout button.
The website gets update as soon as the database gets some input from hardware .
The hardware triggers as the tile got sense of any pressure and that each pressure is counted as one step and from that one step many components gets calculated 
like total energy calculated , total steps and many more.
